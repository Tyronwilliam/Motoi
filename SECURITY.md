# Security Policy

If you discover a security vulnerability in this repository or in the published `@motoi/kata` package, please report it privately rather than opening a public issue.

**Contact:** tyronwilliamchanu@gmail.com

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- Any relevant version/commit information.

We'll acknowledge your report and work on a fix as quickly as possible.
